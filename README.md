# 弥月Mizuki Q 宠使用教程

## 下载

下载 [mizuki-codex-pet.zip](https://github.com/sssccchao/mizuki-codex-pet/releases/latest/download/mizuki-codex-pet.zip) 并解压。

## 安装

将解压得到的 `pet.json` 和 `spritesheet.png` 复制到对应目录，目录不存在时先创建：

| 系统 | 安装目录 |
| --- | --- |
| Windows | `%USERPROFILE%\.codex\pets\mizuki\` |
| macOS | `~/.codex/pets/mizuki/` |

两个文件直接放在 `mizuki` 文件夹内。

## 在 Codex 中使用

1. 打开 Codex 桌面端，在“设置 → 宠物（Pets）”中点击“刷新（Refresh）”。
2. 选择「弥月Mizuki」。
3. 输入 `/pet`，或选择“显示宠物（Show pet）”。再次输入 `/pet` 可隐藏。
